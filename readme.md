# D&D 5e Character Manager

## Sobre o Projeto

O D&D 5e Character Manager é uma aplicação web para criação e gerenciamento de personagens de Dungeons & Dragons 5ª Edição. Desenvolvido com HTML, CSS e JavaScript puro, o projeto oferece uma interface intuitiva e acessível para jogadores criarem, salvarem e gerenciarem seus personagens de RPG.

## Funcionalidades

- **Criação de Personagem**: Interface para criação rápida de personagens com raças, classes e atributos oficiais do D&D 5e
- **Ficha de Personagem**: Visualização completa de todos os atributos, perícias e características do personagem
- **Gerenciamento de Habilidades e Magias**: Visualização de habilidades de classe e magias disponíveis para o personagem
- **Gerenciamento de Equipamentos**: Sistema para adicionar, remover e organizar equipamentos
- **Sistema de Experiência**: Acompanhamento do progresso do personagem com barra visual de XP
- **Salvamento Local**: Armazenamento de personagens no navegador através de localStorage
- **Exportação de Ficha**: Possibilidade de exportar a ficha em PDF
- **Histórico de Personagens**: Lista de personagens criados anteriormente com opções de carregamento e exclusão

## Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3 e JavaScript Vanilla (ES6+)
- **API**: Integração com a D&D 5e API para obtenção de dados oficiais do jogo
- **Armazenamento**: LocalStorage para salvar personagens
- **Responsividade**: Design responsivo para funcionar em dispositivos móveis e desktop
- **PDF**: Biblioteca para exportação de fichas em formato PDF

## Como Usar

1. Acesse a página inicial e clique em "Criar Personagem"
2. Preencha os detalhes básicos como nome, raça e classe
3. Clique em "Gerar Personagem" para criar automaticamente os atributos e características
4. Explore as diferentes abas para visualizar e gerenciar habilidades, magias e equipamentos
5. Salve seu personagem utilizando o botão "Salvar Personagem"

## Estrutura de Arquivos

- **index.html**: Página inicial do projeto
- **personagem.html**: Página de criação e gerenciamento de personagem
- **abilities.html**: Página de visualização de habilidades e magias
- **equipment.html**: Página de gerenciamento de equipamentos
- **adventure.html**: Página de modo aventura
- **css/**: Arquivos de estilo
- **js/**: Scripts JavaScript para funcionalidades específicas
